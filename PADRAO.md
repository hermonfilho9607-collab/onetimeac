## 1. O que TODOS fazem (obrigatório no padrão)

1. **Telefone em todo lugar** — 2 a 6 links `tel:` por página (topo, header, hero, CTA final, rodapé).
2. **Header com CTA de ação** — "Schedule Service", "Book Online", "Get a Quote". Sempre um botão colorido destacado.
3. **Hero com foto escura + título grande com a cidade** — ex.: "HVAC Services in Brooklyn". Foto real (técnico, van, equipamento) com overlay escuro.
4. **Grade de serviços** — mínimo: Reparo, Instalação, Manutenção. Os maiores listam 10–20 serviços no menu.
5. **Prova social** — avaliações (Google/Birdeye) ou depoimentos com nome.
6. **Área atendida** — bairros/cidades citados por nome (SEO local).
7. **Rodapé com NAP** — Nome, Endereço, Telefone + horário + links de serviços.
8. **Widget de chat flutuante** (Housecall Pro, HubSpot) em 3 de 5 sites.

## 2. O que os MELHORES fazem (diferencial)

- **Formulário no hero** (NY Heating): o visitante pede orçamento sem rolar a página.
- **Oferta com número** — "Rebates up to $X", "Financing available", "$X off". Dá motivo para ligar *agora*.
- **FAQ** respondendo preço, licença e prazo — quebra objeção e ajuda SEO.
- **"Como funciona" em 3 passos** — reduz medo de contratar.
- **Selos de confiança** — Licensed & Insured, EPA Certified, anos de experiência, nota no Google.
- **Atendimento 24/7 destacado** — emergência é o maior gatilho do nicho.

## 4. Visual

- **Cores:** base **azul-marinho** (confiança) + **acento quente** (vermelho/laranja/amarelo) só para CTAs. Os 5 sites seguem isso:
  - Taylor: azul `#193193` + rosa-vermelho `#D94263`
  - 212 HVAC: marinho quase preto `#091927` + amarelo/azul-claro
  - NY Heating: marinho `#0A2573` + vermelho `#EA0F14` (patriótico)
  - Energo: azul `#082398` + fundos `#EEF4FA`
  - Patriot: escuro + vermelho `#FF1A00`
- **Fontes:** sans-serif robustas (Raleway, Helvetica, Open Sans, Source Sans). Títulos grandes, pesados, às vezes em CAIXA ALTA.
- **Fotos:** reais (técnico uniformizado, van com logo, equipamento instalado). Nunca banco de imagem genérico se puder evitar.
- **Seções** alternando fundo branco / cinza-azulado claro / marinho.

## 5. Fórmulas de texto (copy)

- **Title (SEO):** `{Serviço principal} in {Cidade}, {Estado} | {Marca}`
- **Meta description:** `{Promessa}. {Serviços} in {Cidade}. Licensed & insured, 24/7. Call {telefone}.`
- **H1:** `{Serviço} in {Cidade}` ou `{Cidade}'s Trusted {Serviço} Experts`
- **Subtítulo:** 3 adjetivos curtos — "Fast. Honest. Licensed." — ou uma promessa concreta ("Same-day repairs, upfront pricing").
- **CTAs:** "Call Now", "Get a Free Estimate", "Schedule Service", "Book Online".
- **Gatilhos recorrentes:** 24/7, same-day, licensed & insured, upfront pricing, satisfaction guaranteed, X years, financing, rebates.

## 6. SEO local (checklist)

- [ ] Cidade/bairro no title, H1, meta description e rodapé
- [ ] Schema `HVACBusiness` (JSON-LD) com nome, telefone, endereço, horário, nota
- [ ] Lista de áreas atendidas por nome
- [ ] FAQ em texto (não imagem)
- [ ] Telefone clicável (`tel:`) em todos os pontos
- [ ] Links UTM do Google Business Profile apontando para a home (como os sites de referência fazem: `?utm_source=GMB`)

## 7. Como usar o template

> O padrão inteiro também está em formato estruturado em `padrao.json` (para usar com outras ferramentas ou IAs).

1. Copie `clientes/exemplo.json` para `clientes/nome-do-cliente.json`.
2. Troque nome, telefone, cidade, serviços, cores, avaliações, áreas e FAQ.
3. Rode:
   ```
   node gerar.js clientes/nome-do-cliente.json
   ```
4. O site sai em `saida/nome-do-cliente/index.html`, pronto para subir na hospedagem.
5. Coloque a foto do hero em `saida/nome-do-cliente/` e aponte `hero_image` no JSON (ou use uma URL).
6. Para o formulário funcionar, cole o endpoint em `form_action` (ex.: Formspree, Basin, Getform).

> **Atenção:** use os sites de referência só como padrão de estrutura. Textos, fotos e avaliações de cada cliente precisam ser **reais e do próprio cliente** — nunca copie depoimentos ou fotos de outros sites.
